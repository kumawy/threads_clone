# Threads Implementation Plan

> For agentic workers: execute independent UI modules in parallel; verify the integrated app before delivery.

**Goal:** A runnable local SwiftUI Threads app faithful to Figma.

**Architecture:** Shared @Observable ThreadsStore, Codable models, feature views and reusable visual components. Root owns tab selection, drawer and composer presentation.

**Tech Stack:** Swift 5, SwiftUI, iOS 17+, XcodeGen, XCTest.

**Spec:** ../specs/2026-11-08-threads-design.md

## Global Constraints

- Exact Russian design copy and locally downloaded Figma assets.
- No backend, no external dependencies, iPhone portrait, dark theme.
- Native keyboard and status bar; adaptive width and accessible buttons.

## Review Focus

- Empty and oversized posts cannot publish.
- Local edits survive relaunch and corrupt persistence recovers safely.
- Composer cancellation does not publish a post.
- Filtering leaves each screen usable when no matching content exists.
- Scroll content clears the floating dock and keyboard.
